Privacy note

Schengen Days is a static calculator. There is no account and no server that receives your travel history.

Your stays

Stays and planning dates are stored in your browser's localStorage on this device. They are never uploaded by the app. Exporting creates a file locally; importing reads a file you choose. Anyone with access to this browser profile can read the data, so use the Delete all data button in the footer on a shared device.

Usage statistics

On the production site, anonymous, cookieless usage statistics are collected with GoatCounter. GoatCounter receives the page path, page title, referrer, screen width, browser user agent, and the request's IP address (used by the service to serve and count the request). The app sends feature events such as "backup-imported" or "donate-clicked"; stay dates, labels, and the contents of your calendar are never included. Analytics is disabled in development builds and is not used for advertising or profiling.

You can opt out in this browser by visiting /#toggle-goatcounter. The setting is stored locally under the skipgc key and can be undone by visiting the same link again.

Hosting

The site is served by GitHub Pages. GitHub may process standard request data such as IP addresses and user agents in its server logs under its own privacy terms. This site sets no cookies of its own.
